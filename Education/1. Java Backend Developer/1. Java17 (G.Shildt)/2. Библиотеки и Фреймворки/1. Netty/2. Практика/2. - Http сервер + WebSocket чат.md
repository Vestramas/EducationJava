Напишем простой Http сервер, который будет выдавать статические страницы HTML по запросу на определенный endpoint. С помощью этих страниц можно будет создавать/удалять/редактировать пользователей (CRUD)

Также предусмотрим простой WebSocket чат с групповой рассылкой, когда один пользователь отправляет сообщение, и оно приходит всем пользователям сразу

# 1. Архитектура

![[Pasted image 20260926114900.png]]

Пайплайн канала будет выглядеть следующим образом:
- `HttpServerCodec` - Кодек HTTP в начале (для кодирования/декодирования байтов)
- `HttpObjectAggregator` - Агрегатор пакетов HTTP
- `ServerRouter` - маршрутизатор по контроллерам
- `WebSocketServerProtocolHandler` - класс который упрощает работу с WebSocket (делает hanshake, обновление пайплайна после Upgrade запроса)
- `ChatWebSocketHandler` - обработчик канала WebSocket


Когда запрос приходит на ServerRouter, то он маршрутизирует запрос на нужный контроллер исходя из URL запроса. 
**Маппинг путей заранее прописывается**

Контроллеры:
- `RequestController` - интерфейс, который определяет методы контроллеров: 
	- Загрузка страницы
	- GET\POST\PUT\DELETE запросы
	
- `IndexController` - стартовая страница
- `UserController` - страница для CRUD операций
- `ChatController` - страница чата

Сначала сервер будет отдавать страницы для CRUD операций над пользователями. Пользователи будут храниться в in-memory, без БД.

Когда пользователь переходит на страницу с чатом, и нажимает кнопку для начала работы WebSocket, то отправляется Upgrade запрос для перехода канала на WebSocket.

После этого, работает полноценный *чат с широковещательной рассылкой сообщений*

## 4.2. Утилитарные методы для создания ответов, и парсинга запросов

### 1 HttpRequestUtil

Из запроса нам нужно уметь доставать:
- чистый uri (без http://), чтобы в ServerRouter маршрутизировать запрос
- параметры из URL

```java
package http.utils;

import com.fasterxml.jackson.core.type.TypeReference;
import com.fasterxml.jackson.databind.ObjectMapper;
import io.netty.handler.codec.http.FullHttpRequest;
import io.netty.handler.codec.http.QueryStringDecoder;
import lombok.extern.slf4j.Slf4j;

import java.io.IOException;
import java.io.UnsupportedEncodingException;
import java.net.URLDecoder;
import java.nio.charset.StandardCharsets;
import java.util.HashMap;
import java.util.Map;

@Slf4j
public class HttpRequestUtil {

    public static String getClearUri(String uriWithParams){
        // /users?id=1 -> /users
        return new QueryStringDecoder(uriWithParams).path();
    }
    public static Map<String, String> getQueryParams(String uri) {
        QueryStringDecoder decoder = new QueryStringDecoder(uri);

        Map<String, String> params = new HashMap<>();

        decoder.parameters().forEach((key, values) -> {
            if (!values.isEmpty()) {
                params.put(key, values.get(0));
            }
        });

        log.debug("Expected query params: {}", params);
        return params;
    }
}
```

### 2 HttpResponseUtil
Чтобы не писать в каждом классе код для создания ответа, напишем утилитарный класс, который создает ответ с телом и нужным кодом ответа

```java
package http.utils;

import io.netty.buffer.Unpooled;
import io.netty.handler.codec.http.*;
import jdk.jfr.ContentType;

import java.nio.charset.StandardCharsets;

public class HttpResponseUtil {
    private HttpResponseUtil() {}

    public static FullHttpResponse createResponse(
        byte[] body,
        HttpResponseStatus status,
        ContentTypes contentType
    ) {

        FullHttpResponse response =
            new DefaultFullHttpResponse(
                HttpVersion.HTTP_1_1,
                status,
                Unpooled.wrappedBuffer(body)
            );

        response.headers().set(
            HttpHeaderNames.CONTENT_TYPE,
            contentType.getValue()
        );

        response.headers().setInt(
            HttpHeaderNames.CONTENT_LENGTH,
            body.length
        );

        return response;
    }
}
```

## 4.4 UserController
Контроллер, который:
- отдает страницу для работы с пользователями
- принимает и обрабатывает запросы (**префикс в URL** - `api` **добавляется внутри страницы**)

Всех добавленных пользователей храним в списке. При создании пользователя внутри контроллера инкрементируется счетчик - ID пользователя.

**Пользователю возвращаем полный список пользователей**, а не по ID. Иначе бы если ID=index, тогда при удалении нужно было бы править ID у всех пользователей, если бы нужно было вернуть только одного пользователя

> **ВАЖНО** 
> ID != index в списке.

```java
package http.server.controller;

import com.fasterxml.jackson.core.JsonProcessingException;
import com.fasterxml.jackson.databind.ObjectMapper;
import http.model.User;
import http.utils.ContentTypes;
import http.utils.HttpRequestUtil;
import http.utils.HttpResponseUtil;
import io.netty.handler.codec.http.*;
import lombok.extern.slf4j.Slf4j;

import java.io.FileInputStream;
import java.io.IOException;
import java.io.InputStream;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.concurrent.CopyOnWriteArrayList;
import java.util.concurrent.atomic.AtomicInteger;

@Slf4j
public class UserController implements RequestController {
    private static List<User> USERS = new CopyOnWriteArrayList<>();
    private static ObjectMapper mapper = new ObjectMapper();

    private static AtomicInteger counter = new AtomicInteger(0);

    @Override
    public FullHttpResponse getPageHandle() {
        try(InputStream inputStream =
                getClass()
	                .getClassLoader().getResourceAsStream("users.html")
        ){
            if (inputStream == null) {
                return HttpResponseUtil.createResponse(
                    "Not found!".getBytes(),
                    HttpResponseStatus.NOT_FOUND,
                    ContentTypes.JSON
                );
            }

            return HttpResponseUtil.createResponse(
                inputStream.readAllBytes(),
                HttpResponseStatus.OK,
                ContentTypes.HTML
            );

        } catch (IOException e) {
            throw new RuntimeException(e);
        }
    }

    @Override
    public FullHttpResponse getMethodHandle(FullHttpRequest request) {
        try {
            return HttpResponseUtil.createResponse(
                mapper.writeValueAsBytes(USERS),
                HttpResponseStatus.OK,
                ContentTypes.JSON
            );
        } catch (JsonProcessingException e) {
            throw new RuntimeException(e);
        }
    }

    @Override
    public FullHttpResponse postMethodHandle(FullHttpRequest request) {
        byte[] payload = new byte[request.content().readableBytes()];

        try {
            request.content().readBytes(payload);

            User user = mapper.readValue(payload, User.class);
            user.setId(counter.incrementAndGet());
            USERS.add(user);

            return HttpResponseUtil.createResponse(
                mapper.writeValueAsBytes(user),
                HttpResponseStatus.CREATED,
                ContentTypes.JSON
            );

        } catch (IOException e) {
            log.error(
	            "Exception on parsed JSON of User: {}", e.getMessage());
            throw new RuntimeException(e);
        }
    }

    @Override
    public FullHttpResponse deleteMethodHandle(FullHttpRequest request) {
        Map<String, String> queryParams = HttpRequestUtil
	        .getQueryParams(request.uri());

        int deletedUserId = Integer.parseInt(
            queryParams.getOrDefault("id", String.valueOf(-1)));

        if(deletedUserId < 0){
            return HttpResponseUtil.createResponse(
                "Not found".getBytes(),
                HttpResponseStatus.NOT_FOUND,
                ContentTypes.JSON);
        }
        log.info("Before deleted: {}", USERS);

        USERS.removeIf(u -> u.getId() == deletedUserId);

        log.info("After deleted: {}", USERS);

        return HttpResponseUtil.createResponse(
            "".getBytes(StandardCharsets.UTF_8),
            HttpResponseStatus.OK,
            ContentTypes.JSON
        );
    }

    @Override
    public FullHttpResponse putMethodHandle(FullHttpRequest request) {
        Map<String, String> queryParams = HttpRequestUtil
	        .getQueryParams(request.uri());

        int updateUserId = Integer.parseInt(
            queryParams.getOrDefault("id", String.valueOf(-1)));

        if(updateUserId < 0){
            return HttpResponseUtil.createResponse(
                "Not found".getBytes(),
                HttpResponseStatus.NOT_FOUND,
                ContentTypes.JSON);
        }

        byte[] payload = new byte[request.content().readableBytes()];
        request.content().readBytes(payload);

        try{
            User updatableUser = mapper.readValue(payload, User.class);

            log.info("Before update: {}", USERS);

            USERS.stream()
                .filter(u -> u.getId() == updateUserId)
                .findFirst()
                .ifPresent(u -> {
                    u.setName(updatableUser.getName());
                    u.setEmail(updatableUser.getEmail());
                });

            log.info("After update: {}", USERS);

            return HttpResponseUtil.createResponse(
                mapper.writeValueAsBytes(updatableUser),
                HttpResponseStatus.OK,
                ContentTypes.JSON
            );
        } catch (IOException e) {
            throw new RuntimeException(e);
        }
    }
}
```

# 5. ServerRouter
Теперь опишем маршрутизатор, который при помощи утилитарных классов получает чистый URI из запроса, и по этому URI и методу HTTP вызывает котроллер

```java
package http.server;

import http.server.controller.ChatController;
import http.server.controller.RequestController;
import http.server.controller.IndexController;
import http.server.controller.UserController;
import http.utils.ContentTypes;
import http.utils.HttpRequestUtil;
import http.utils.HttpResponseUtil;
import io.netty.channel.ChannelHandlerContext;
import io.netty.channel.SimpleChannelInboundHandler;
import io.netty.handler.codec.http.*;
import lombok.extern.slf4j.Slf4j;

import java.util.HashMap;
import java.util.Map;

@Slf4j
public class ServerRouter extends SimpleChannelInboundHandler<FullHttpRequest> {
    private static final Map<String, RequestController> routingMap = createRoutes();
	
	// Маппинг URI на контрлллер
    private static Map<String, RequestController> createRoutes() {
        Map<String, RequestController> routes = new HashMap<>();

        UserController userController = new UserController();

        routes.put("/index", new IndexController());
        routes.put("/users", userController);
        routes.put("/api/users", userController);
        routes.put("/chat", new ChatController());

        return routes;
    }

    @Override
    protected void channelRead0(
	    ChannelHandlerContext ctx, 
	    FullHttpRequest msg
	) {
        byte[] contentPayload = new byte[msg.content().readableBytes()];
        msg.content().getBytes(0, contentPayload);

        log.info("""
            Received message
                Method: {}
                URI: {}
                Headers: {}
                Remote address: {}
                Content: {}
                Channel ID: {}
            """,
            msg.method(),
            msg.uri(),
            msg.headers(),
            ctx.channel().remoteAddress(),
            new String(contentPayload),
            ctx.channel().id()
        );

        log.info("Channel ID: {}", ctx.channel().id());

        if(isWebSocketUpgrade(msg)){
	        // ПЕРЕДАЕМ ЗАПРОС СЛЕДУЮЩЕМУ ПО ПАЙПЛАЙНУ ОБРАБОТЧИКУ
	        // Т.Е WebSocketServerProtocolHandler а тот в свою очередь 
	        // нашему обработчику WS
            ctx.fireChannelRead(msg.retain());
            return;
        }
        handleHttpRequest(ctx, msg);
    }

    private void handleHttpRequest(
	    ChannelHandlerContext ctx, 
	    FullHttpRequest msg
	) {
        String uri = HttpRequestUtil.getClearUri(msg.uri());

        RequestController controller = routingMap.getOrDefault(uri, null);

        if (controller != null) log.info(
	        "Routing to {}", controller.getClass().getName()
        );

        FullHttpResponse response;
        try{
            if (controller == null) {
                response = HttpResponseUtil.createResponse(
                    "Not found! Controller for this URI".getBytes(),
                    HttpResponseStatus.NOT_FOUND,
                    ContentTypes.JSON
                );;
            } else {
                HttpMethod method = msg.method();
                if (method.equals(HttpMethod.GET)) {
                    if (uri.contains("api")) {
                        response = controller.getMethodHandle(msg);
                    } else {
                        response = controller.getPageHandle();
                    }
                } else if (method.equals(HttpMethod.POST)) {
                    response = controller.postMethodHandle(msg);

                } else if (method.equals(HttpMethod.PUT)) {
                    response = controller.putMethodHandle(msg);

                } else if (method.equals(HttpMethod.DELETE)) {
                    response = controller.deleteMethodHandle(msg);

                } else {
                    response = HttpResponseUtil.createResponse(
                        "Bad request! Unsupported method".getBytes(),
                        HttpResponseStatus.BAD_REQUEST,
                        ContentTypes.JSON
                    );;
                }
            }
            ctx.writeAndFlush(response);
        } catch (Exception e) {
            log.error("Exception on routing request: ", e);
            throw new RuntimeException(e);
        }
    }

    private boolean isWebSocketUpgrade(FullHttpRequest request) {
        return request.headers().contains(
                HttpHeaderNames.UPGRADE,
                HttpHeaderValues.WEBSOCKET,
                true
            )
            && "/chat-ws".equals(
	            HttpRequestUtil.getClearUri(request.uri())
	        );
    }
}

```

# 6. ChatWebSocketHandler - Обработчик WS соединений
Теперь опишем см обработчик WS соединений. После Upgrade канала на WebSocket, входящие сообщения будет принимать именно этот обработчик.

Запрос же теперь не будет проходить цепочку до ServerRoute, а будет сразу попадать на этот обработчик

```java
package http.server;

import io.netty.channel.Channel;
import io.netty.channel.ChannelHandlerContext;
import io.netty.channel.SimpleChannelInboundHandler;
import io.netty.channel.group.ChannelGroup;
import io.netty.channel.group.DefaultChannelGroup;
import io.netty.handler.codec.http.websocketx.TextWebSocketFrame;
import io.netty.handler.codec.http.websocketx.WebSocketServerProtocolHandler;
import io.netty.handler.timeout.IdleStateEvent;
import io.netty.util.concurrent.GlobalEventExecutor;
import lombok.extern.slf4j.Slf4j;


// Класс наследует обычный обработчик канала, НО ТИП ПРИНИМАЮЩЕГО СООБЩЕНИЯ ЭТО - TextWebSocketFrame
@Slf4j
public class ChatWebSocketHandler 
extends SimpleChannelInboundHandler<TextWebSocketFrame> {

    private static final ChannelGroup CHANNELS = 
	    new DefaultChannelGroup(GlobalEventExecutor.INSTANCE);
	
	// Метод срабатывает каждый раз, когда клиент делает UPGRADE запрос
	// после ServerRoute. Так как именно ServerRotue передает запрос на 
	// следующий обработчик в пайплайне
    @Override
    public void userEventTriggered(
	    ChannelHandlerContext ctx, 
	    Object evt
	) throws Exception {
	
        if (evt instanceof WebSocketServerProtocolHandler.HandshakeComplete handshakeComplete) {
            log.info(
	            "WebSocket handshake complete: {} \n\tChannel ID: {}",
                handshakeComplete.requestUri(),
                ctx.channel().id());
			
			// Каждый новый клиентский канал добавляем в группу для 
			// рассылки сообщений
            CHANNELS.add(ctx.channel());

        } else {
            super.userEventTriggered(ctx, evt);
        }
    }

    @Override
    protected void channelRead0(
	    ChannelHandlerContext ctx, 
	    TextWebSocketFrame msg
	) throws Exception {
        log.info("WebSocket received: {}", msg.text());

        String message = "Server: " + msg.text();
		
		// Отправляем всем каналам WS сообщения
        CHANNELS.writeAndFlush(new TextWebSocketFrame(message));
    }

    @Override
    public void channelInactive(
	    ChannelHandlerContext ctx
	) throws Exception {
        log.info("Channel inactive: {}", ctx.channel().id());

        CHANNELS.remove(ctx.channel());

        //super.channelInactive(ctx); Нужно ли оставить?
    }
}
```

```java
package http.server;

import io.netty.channel.ChannelInitializer;
import io.netty.channel.ChannelPipeline;
import io.netty.channel.socket.SocketChannel;
import io.netty.handler.codec.http.HttpObjectAggregator;
import io.netty.handler.codec.http.HttpServerCodec;
import io.netty.handler.codec.http.websocketx.WebSocketServerProtocolConfig;
import io.netty.handler.codec.http.websocketx.WebSocketServerProtocolHandler;

public class HttpServerInitializer extends ChannelInitializer<SocketChannel> {

    private static final WebSocketServerProtocolConfig WEB_SOCKET_CONFIG =
        WebSocketServerProtocolConfig
            .newBuilder()
             .websocketPath("/chat-ws")
             .build();

    @Override
    protected void initChannel(SocketChannel ch) {
        ChannelPipeline pipeline = ch.pipeline();

        pipeline.addLast(new HttpServerCodec());
        pipeline.addLast(new HttpObjectAggregator(65536));
        pipeline.addLast(new ServerRouter());
        // Добавление WebSocket обработчиков
        pipeline.addLast(
	        new WebSocketServerProtocolHandler(WEB_SOCKET_CONFIG));
        pipeline.addLast(new ChatWebSocketHandler());
    }
}
```

# 8. Сервер
Теперь опишем сервер, который будет принимать запросы на подключение, и передавать запрос в пайплайн

```java
package http.server;

import io.netty.bootstrap.ServerBootstrap;
import io.netty.channel.ChannelFuture;
import io.netty.channel.EventLoopGroup;
import io.netty.channel.nio.NioEventLoopGroup;
import io.netty.channel.socket.nio.NioServerSocketChannel;
import io.netty.handler.logging.LoggingHandler;
import lombok.extern.slf4j.Slf4j;

import java.net.InetSocketAddress;
import java.util.logging.Logger;

@Slf4j
public class HttpServer {
    private EventLoopGroup bossGroup;
    private EventLoopGroup workerGroup;
    private static int port = 8080;
    private static String host = "localhost";

    public static void main(String[] args) {
        new HttpServer().start();

    }

    public void start(){
        bossGroup = new NioEventLoopGroup(1);
        workerGroup = new NioEventLoopGroup();

        log.info("Server configuration");
        ServerBootstrap bootstrap = new ServerBootstrap();
        bootstrap.group(bossGroup, workerGroup)
            .localAddress(new InetSocketAddress(host, port))
            .channel(NioServerSocketChannel.class)
            .handler(new LoggingHandler())
            // Наш описанный пайлпайн
            .childHandler(new HttpServerInitializer());

        try{
            ChannelFuture future = bootstrap.bind().sync();
            log.info("Server started");
            future.channel().closeFuture().sync();
        } catch (InterruptedException e) {
            e.printStackTrace();
        } finally {
            stop();
        }
    }

    public void stop(){
        bossGroup.shutdownGracefully();
        workerGroup.shutdownGracefully();
    }
}
```
